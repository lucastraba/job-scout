# Jane Doe

This is the example profile, a fictional person. `job-scout guide setup` rewrites it from the real person's CV and an interview.

## Who she is
- Frontend lead, 10 years building web products. At her last company she built the React/TypeScript design system and led a team of four.
- Wants frontend platform, design-system and frontend leadership roles.
- Strongest at foundations: component libraries, build tooling, onboarding, code review culture.
- Stack: TypeScript, React (deep), Vue (some), Vite, Storybook, Playwright. No mobile, no backend-only work.
- Languages: English and Portuguese. No German.
- Full CV: `cvs/Jane-Doe-CV.pdf`. Only read it if a posting needs a closer comparison.

## Hard requirements (a posting that breaks one scores 3 or lower)
- Fully remote and open to someone living in an EU country. Single-EU-country remote roles are allowed but score lower. Hybrid, on-site, US-only and UK-only roles fail.
- No German requirement.
- Senior or above.
- Mainly frontend, full-stack TypeScript, design systems or frontend leadership.

## Score out of 10
| Part | Points |
|---|---|
| Lane fit: frontend platform / design systems, frontend lead or EM | 0–4 |
| Stack: React + TypeScript = 2, Vue + TypeScript = 1, other = 0 | 0–2 |
| Seniority and scope: lead/staff/principal/EM = 2, senior with ownership = 1 | 0–2 |
| Remote certainty: explicit EU/Europe/EMEA/worldwide = 2, one EU country or unclear = 1, doubtful = 0 | 0–2 |

## Lanes
- `frontend-platform`: design systems, frontend architecture, developer experience.
- `people-lead`: frontend lead, engineering manager.
- `other`: anything else that still fits.

## What to say in `why` and `gaps`
`why`: mention design systems, React/TypeScript, or team-building signals when present.
`gaps`: remote fine print, stack mismatch, listed salary below €70k/year gross, contract-only.
